# ALB Saver

Werbefreier Downloader für Instagram (Posts, Reels, Karussells, Stories, Highlights) und Facebook (Videos, Reels).

## Benutzung
1. App öffnen → „Bei Instagram anmelden“ (bzw. Facebook) → einloggen → „Fertig“.
2. In Instagram/Facebook auf **Teilen** tippen → **ALB Saver** wählen, oder den Link kopieren und in der App „Herunterladen“ tippen.
3. Dateien landen in `Filme/ALBSaver` und `Bilder/ALBSaver` und erscheinen in der Galerie.

Private Inhalte gehen nur, wenn dein Konto Zugriff darauf hat (z. B. du folgst der Person).

## APK bauen
- **GitHub:** Projekt in ein Repo pushen → Actions baut automatisch → APK unter *Releases* oder *Actions → Artefakte*.
- **Android Studio:** Ordner öffnen → Build → Build APK(s).

Benötigt Android 10 oder neuer.
